  Implementation Summary

  1. Edge Detection Functions (ppd/utils/align_depth_func.py)

  Added two edge detection methods:
  - detect_depth_edges(): Gradient-based edge detection using Sobel operators
  - detect_canny_edges(): Canny edge detector for depth maps

  Both return a binary mask (1=edges, 0=interior) with configurable dilation to
  expand edge regions.

  2. Masked Sampler (ppd/utils/diffusion/masked_sampler.py)

  Created MaskedEulerSampler class that:
  - Extends EulerSampler to support mask-based region preservation
  - Injects known depth values (MoGe-2 interior) during sampling
  - Similar to RePaint's approach: x = keep_mask * noised_known + (1 - 
  keep_mask) * x_t
  - Includes initialize_latent_with_mask() to start with known regions preserved

  3. Hybrid Inference Method (ppd/models/ppd.py)

  Added infer_hybrid() method to PixelPerfectDepth that:
  - Takes MoGe-2 depth map and edge mask as input
  - Resizes both to match model resolution
  - Creates keep_mask (1=interior, 0=edges)
  - Runs masked diffusion sampling preserving interior regions
  - Returns hybrid depth combining MoGe-2 metric accuracy with PPD edge quality

  4. Main Pipeline Script (run_hybrid_depth.py)

  Complete script with arguments:
  - --edge_detection: Choose 'gradient' or 'canny'
  - --gradient_threshold: Threshold for gradient-based detection
  - --dilation_iter: Expand edge mask by this many iterations
  - --save_edge_mask: Save edge mask visualization
  - --save_moge: Save MoGe-2 depth for comparison
  - --save_npy: Save raw depth as .npy

  Usage

  # Basic usage
  python run_hybrid_depth.py --img_path assets/examples/images

  # With Canny edge detection and visualizations
  python run_hybrid_depth.py --img_path assets/examples/images \
      --edge_detection canny \
      --save_edge_mask \
      --save_moge

  # Adjust edge detection parameters
  python run_hybrid_depth.py --img_path assets/examples/images \
      --edge_detection gradient \
      --gradient_threshold 0.03 \
      --dilation_iter 5

  The pipeline leverages MoGe-2's metric depth accuracy for interior regions
  while using PixelPerfectDepth's flying-pixel-free edge reconstruction for
  boundary regions, resulting in a depth map that is both metrically accurate
  and geometrically clean at edges.
