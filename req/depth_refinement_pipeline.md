# 混合绝对深度估计流水线：MoGe-2 + Pixel-Perfect Depth

## 🎯 目标
开发一个两阶段流水线，结合 **MoGe-2**（用于度量尺度的绝对深度）和 **Pixel-Perfect Depth**（用于边缘感知的精细化），从单张 RGB 图像生成高保真、无飞行像素的绝对深度图。

核心思想是利用 MoGe-2 在**全局度量精度**方面的优势，以及 Pixel-Perfect Depth 在**像素级完美边界重建**方面的优势，使用 **RePaint 启发的基于扩散的修复**策略和**重采样**来无缝整合两者。

---

## 🔧 流水线概览

1. **阶段 1：使用 MoGe-2 生成绝对深度**
   - 输入：单张 RGB 图像 (`input.jpg`)
   - 输出：初始绝对深度图 `D_moge`（单位：米），以及有效性掩码 `M_valid`。

2. **阶段 2：使用 Pixel-Perfect Depth 进行边缘感知精细化（RePaint 风格）**
   - 识别 `D_moge` 中的**边缘/边界区域**作为"修复掩码" `M_edge`。
   - 使用 **Pixel-Perfect Depth** 的扩散模型在**条件修复模式**下：
     - 以输入 RGB 图像为条件。
     - 应用 **带重采样的 RePaint 算法**（见下面的算法 1）。
     - 仅在 `M_edge` 内重新生成深度值，保留其他区域的 `D_moge`。
   - 输出：精细化后的绝对深度图 `D_refined`，既在**度量上准确**，又在**物体边界处几何清晰**。

---

## 📐 详细需求

### 1. MoGe-2 集成
- 使用 **Pixel-Perfect Depth 仓库中的 MoGe-2 模型**（`moge2.py` 或等效文件）。
- 通过 `torch.load("path/to/moge2.pth")` 加载模型。
- 对输入 RGB 图像运行推理以获得：
  - `depth`：绝对深度图（H×W，float32，单位 = 米）
  - `mask`：有效性掩码（H×W，bool）

> 💡 *注意：这避免了外部依赖；仅使用 Pixel-Perfect Depth 代码库中包含的模型。*

### 2. 边缘掩码生成
- 从 `D_moge` 计算**边缘掩码** `M_edge`：
  - 对 `D_moge` 使用梯度幅值（例如 Sobel 滤波器）
  - 阈值化得到二值掩码：`M_edge = (grad_depth > threshold)`
  - 可选择膨胀 1-2 个像素以包含近边界区域
- `M_edge` 应该是一个二值掩码，其中：
  - `1` = 需要精细化的区域（物体边界、潜在的飞行像素）
  - `0` = 保留原始 MoGe-2 深度

#### 关键步骤：
- 设 `x_t` 为步骤 `t` 时的当前噪声深度估计。
- 对于从 `T` 降至 `1` 的每个时间步 `t`：
  - 对于 `u = 1,...,U`（重采样步数）：
    - **已知区域**（来自 MoGe-2）：
      `x_{t-1}^{known} = √ᾱ_t · D_moge + (1−ᾱ_t)·ε`，其中 `ε ~ N(0,I)`
      → 确保已知区域遵循与 `D_moge` 相同的噪声调度。
    - **未知区域**（待生成）：
      `x_{t-1}^{unknown} = 1/√α_t · (x_t − β_t/√(1−ᾱ_t) · ε_θ(x_t,t)) + σ_t·z`，
      其中 `z ~ N(0,I)` 如果 `t > 1`，否则为 `0`。
    - 组合：
      `x_{t-1} = m ⊙ x_{t-1}^{known} + (1−m) ⊙ x_{t-1}^{unknown}`
      其中 `m = M_edge`（二值掩码）。
    - 如果 `u < U` 且 `t > 1`，从分布**重采样** `x_t`：
      `x_t ~ N(√(1−β_{t-1})·x_{t-1}, β_{t-1}·I)`
- 返回最终的 `x_0` 作为精细化深度。

> ✅ **重采样很关键**：它防止过拟合并提高复杂边缘的一致性。参考RePaint/和RePaint/CLAUDE.md了解重采样过程。如果PePaint/中的实现过程与算法 1不同，请你先预留相关接口，当前先实现算法 1.
